# 🔐 اوت اکانت | Out Account

**اوت اکانت** ابزاری برای ورود و مدیریت نشست (Session) اکانت‌های متعلق به کاربر است.

این سورس با استفاده از شماره تلفن و کد تأیید، فرآیند احراز هویت را انجام داده و پس از ورود موفق، اطلاعات نشست و داده‌های موردنیاز برای اتصال کلاینت یا استفاده در پروژه‌های مرتبط را در اختیار کاربر قرار می‌دهد.

> ⚠️ این ابزار باید صرفاً برای اکانت‌هایی استفاده شود که متعلق به خود کاربر هستند یا کاربر مجوز صریح برای مدیریت آن‌ها را دارد.

## 📋 قابلیت‌ها

* 📱 ورود به اکانت با شماره تلفن
* 🔢 تأیید کد ورود
* 🔐 ایجاد و دریافت اطلاعات Session
* 📦 دریافت اطلاعات موردنیاز برای اتصال کلاینت
* 🔗 آماده‌سازی نشست برای استفاده در پروژه‌های مرتبط
* 👤 بررسی مالکیت/مجوز اکانت در صورت پشتیبانی سیستم

## ⚙️ روند کار

```text
شماره تلفن
    ↓
ارسال کد تأیید
    ↓
تأیید کد
    ↓
احراز هویت موفق
    ↓
دریافت Session
    ↓
دریافت اطلاعات موردنیاز کلاینت
```

## 📝 توضیحات

اوت اکانت با هدف ساده‌سازی فرآیند ورود و مدیریت نشست اکانت‌های کاربر طراحی شده است.

پس از احراز هویت موفق، Session ایجادشده می‌تواند برای اتصال کلاینت یا استفاده در پروژه‌های مرتبط مورد استفاده قرار گیرد؛ مشروط بر اینکه استفاده از آن مجاز بوده و اکانت متعلق به کاربر باشد.

## 🔒 نکات امنیتی

* اطلاعات Session را در اختیار افراد دیگر قرار ندهید.
* Session را داخل Repository عمومی GitHub قرار ندهید.
* اطلاعات حساس را در فایل‌های پروژه یا Commitها ذخیره نکنید.
* از این سورس فقط برای اکانت‌های خودتان یا اکانت‌هایی که اجازه مدیریت آن‌ها را دارید استفاده کنید.

## 🛠️ تکنولوژی

```text
Language: Python
```

کتابخانه‌ها و وابستگی‌های پروژه در فایل `requirements.txt` قرار دارند.

## 🚀 نصب و اجرا

Repository را Clone کنید:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

سپس فایل اصلی پروژه را اجرا کنید:

```bash
python main.py
```

> نام فایل اجرای پروژه را در صورت متفاوت بودن با `main.py` جایگزین کنید.
